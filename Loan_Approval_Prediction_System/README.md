# 🏦 Loan Approval Prediction System

The full project files, trained models, dataset, web dashboard, and API server are located in [`Loan_Approval_Prediction_System/`](Loan_Approval_Prediction_System/).

### Quick Start
To run the web app and REST API server:
```powershell
cd Loan_Approval_Prediction_System
python app.py
```
Then open `http://127.0.0.1:5000` in your web browser.

Alternatively, you can directly open [`Loan_Approval_Prediction_System/index.html`](Loan_Approval_Prediction_System/index.html) in any browser without needing to run a server.

Please see the comprehensive documentation in [`Loan_Approval_Prediction_System/README.md`](Loan_Approval_Prediction_System/README.md).
